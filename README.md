# Agentic wallet (ETHOnline 2026)

Private planning repo for a **web-first agentic wallet**: a Harness-style workspace where a human and an AI share one Chrome, and **Privy** is the leash on what that agent can spend.

Telegram is onboarding (and later, approval cards), not a Mini App as the product.
