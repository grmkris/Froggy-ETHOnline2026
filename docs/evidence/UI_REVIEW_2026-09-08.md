## How it was made

Ran `FROGGY_E2E_PORT=3700 bun run e2e --workers=2 --config=/tmp/froggy-ui-review-2026-09-08/playwright.config.ts` using a temporary config that inherits the repository's explicit stub setup. The default project ran the full 88-test suite; a second project repeated 43 capture-producing tests with Lilypad selected in local storage. The theme and navigation specs explicitly capture both themes during the full-suite run. The [tour README](ui-review-2026-09-08/README.md#how-it-was-made) includes a reproducible configuration.

The existing `captureScreen`, `capturePage` and `captureResponsive` helpers wait for fonts, disable screenshot animations, mask OAuth authorization codes and connection tokens, and walk the internal scroller. Onboarding, service-recovery and Telegram specs also emit screenshots directly. The committed PNGs are unchanged copies, organized by theme and renamed for the gallery.
