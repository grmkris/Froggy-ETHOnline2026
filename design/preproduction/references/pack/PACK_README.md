# Froggy preproduction pack

This pack is a self-contained brief for your coding/design agent. It does not configure anything by itself.

1. Open the Froggy repository or a dedicated design worktree in your agent.
2. Attach this pack, or make its extracted folder available in the workspace. Preserve any existing files.
3. Paste `START_HERE.txt` into the agent and let it inspect the environment before asking you for setup decisions.

The full specification is `FROGGY_PREPRODUCTION_SPEC.md`. It covers discovery, safe tool setup, Rive/Figma/image/browser smoke tests, art direction, assets, motion, screen families, onboarding, service readiness, parallel-agent ownership, QA, and implementation handoff.

The `references/` folder contains the clean screen layout and two earlier playful brand boards, with instructions separating visual inspiration from actual requirements. These images are simulated concepts, not production claims.

This is preproduction, not permission to rebuild the production application. New subscriptions, paid generation, public publishing, production access, and real financial actions remain separate approval steps.

Prepared 10 September 2026. Tool documentation was checked for the specification, but your local/remote environment, installed applications, account entitlements, and live integrations have not been configured or tested by the author of this pack. The agent must verify them.
