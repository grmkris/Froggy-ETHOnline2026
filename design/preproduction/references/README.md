# Froggy visual references

These are AI-generated concept images from the product discussion. They are supplied for art direction, not as finished UI assets, investment guidance, live provider evidence, or verified product data.

## 01 — Clean layout reference

`01-clean-layout-reference.png` is the later four-screen collage the owner liked: Home, Explore, a shopping task with contextual browser, and Wallet. Use its calmer composition, three-item primary navigation, whitespace, and task-focused content as the layout starting point.

Do not copy all its details literally: the new brief overrides the image. Home becomes task-driven For You. Browser content is contextual, not permanent. Correct inconsistent values, labels, example personal details, and any misleading spending/progress displays. The reference contains fictitious prices and financial figures.

## 02 — Playful light brand reference

`02-playful-light-brand-reference.png` is one of the earlier playful directions the owner preferred. Use the frog personality, rounded graphic language, warm/light setting, and lime energy as inspiration. Do not reproduce its dense dashboard, numerous navigation tabs, abundant stickers, financial slogans, APY claims, or busy layout.

## 03 — Playful dark brand reference

`03-playful-dark-brand-reference.png` is the other earlier preferred direction. Use for attitude, character styling, and optional dark-mode ideas. It is not the primary screen-layout target. Do not copy investment promises, reassuring portfolio category labels, or an all-green performance narrative.

## Precedence

The written specification wins over every image. The clean layout reference wins for hierarchy and density. Earlier boards contribute personality only. Create an original, coherent mascot rather than mixing different frog geometries. Text should be real editable UI, not cropped from these images. Third-party marks in concept art do not establish licensing, partnerships, or entitlement.
