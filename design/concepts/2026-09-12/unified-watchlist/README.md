# Home and flexible Watchlist concepts

Generated with the built-in image-generation tool for visual review before implementation planning. Sample data and static proposed UI only.

- [Mobile: Home, Watchlist, and item details](01-mobile.png)
- [Desktop: chat with optional mixed Watchlist](02-desktop.png)

Direction: Home contains chat and a compact Your money summary, with detailed balances/P&L reachable from it. Watchlist combines tokens, flights, products, links, and reminders. Saved links and scheduled checks remain distinguishable. Item details expose source, observation time, schedule and actions. No permanent Markets / Portfolio / Browser tabs.

Generic website price watching is a proposed capability, not a verified integration. Sample merchant imagery, rates, token identities, dates, and task states are illustrative. App source was not changed.
